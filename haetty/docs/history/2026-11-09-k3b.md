# K3b: the own tab name, and the former environment names (2026-11-09)

- **Own name.** Ctrl+Shift+R names a tab; the name was kept in the window only, so a detach and an attach (or a new
  window that takes the session) lost it. It is now kept per session in `state_dir/tab-names.tsv` (set on rename,
  read on reattach).
- **Former environment names.** `CCTERM_*` variables are no longer read (the Windows conpty DLL, the socket, the state
  and config directories, the instance, the session markers in the dev scripts). The file migration of the former
  name (config, tab sets, a running old daemon) stays for one more version.
- Tests: the tab-name file round trip (haetty-gui unit); the migration test keeps its file part.
