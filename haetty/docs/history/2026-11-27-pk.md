### Choices made

- The run directory is removed only when its script ends well: a failed run keeps the logs needed to find the cause.
- The claude guard drops PATH folders instead of only refusing: e2e scripts put their fake claude first and still had
  `~/.local/bin` behind it; dropping it makes a missing fake fail loudly ("command not found") instead of starting
  the real one.
- The stable check reads the start time since boot (`/proc/PID/stat`), because `ps -o lstart` follows the wall
  clock (it moved one hour during PD's 0.4.2 check).
- check-comments counts against the merge base, so check-range's older commits count only their own lines.
